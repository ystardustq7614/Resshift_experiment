## 第 1 页：数据来源与构建方式

### 上屏内容

**标题：XFJ DAS 半合成数据集由合成信号与实测背景噪声组成**

**用途：评估模型能否从真实背景噪声中恢复已知的合成地震信号。**

| 项目 | 内容 |
|---|---|
| 数据集名称 | XFJ DAS 半合成实验交付包（`DAS_Semisynthetic_Test`） |
| 数据来源 | 干净目标 `y` 由程序合成，背景噪声来自真实 DAS 记录的事件前时段 |
| 获取方式 | 通过项目交付包读取现成的 NPY 数组，配套 CSV 元数据和参考构造代码 |
| 使用限制 | 当前实验结论适用于半合成降噪，真实地震上的有效性需另行验证 |
| 数据版本 | 当前交付包未声明正式版本号，配置种子为 `20260711`，已有审计日期为 2026-10-25 |

**构建关系：`x = y + n`。** 合成信号按目标信噪比缩放后叠加实测背景噪声，再按包内说明对 `x`、`y` 使用同一因子归一化。

页脚：采集地点、采集机构、原始采集日期及对外使用许可，当前材料中未明确，待补充。

### 讲解备注（不上屏）

这里的“半合成”指信号与噪声的来源不同。`y` 使用 Ricker 子波、衰减尾波和散射纹理等构造，并加入通道间到时差、幅值变化和 1–40 Hz 带通处理。`n` 从实测记录中事件前的埋地光纤背景时段裁剪、拼接得到，并非简单生成的白噪声。

`y` 是人为已知的目标波形，`x` 是人为混合后的输入。不能将这组数据表述为“真实地震的含噪记录与其真实干净记录”。参考生成代码也没有建立从地下位移场到仪器输出的完整物理正演过程。

获取现成训练数据与从零重新生成数据是两件事。当前包包含构造方法参考，但缺少原始 MAT 噪声库和正式 NPY 的完整批量构建脚本。配置种子、审计日期都只是追溯信息，不能替代正式数据版本号。

## 第 2 页：研究对象、变量与数据规模

### 上屏内容

**标题：每个样本记录 128 个通道在 10.24 秒内的波形变化**

**研究对象：DAS 沿光纤通道的地震信号及背景噪声，数据组织为通道与时间的二维阵列。**

| 变量 | 含义 | 单位 |
|---|---|---|
| `x` | 模型看到的含噪输入波形 | 归一化相对幅值，无量纲 |
| `y` | 希望模型恢复的合成目标波形 | 归一化相对幅值，无量纲 |
| `n = x - y` | 归一化后的背景噪声残差 | 归一化相对幅值，无量纲 |

- **数据维度：**正式数组为 `[样本, 通道, 时间]`，单样本 `128 × 4096`，类型为 `float16`。
- **时间范围：**声明采样率 400 Hz，间隔 2.5 ms，窗口长 10.24 s，最后一个采样点位于 10.2375 s。
- **空间范围：**每个样本含 128 个相对通道，编号 0–127。通道间距及实际覆盖距离待补充。
- **数据规模：**共 312 对样本，训练 / 验证 / 测试为 240 / 36 / 36 对，正式 6 个 NPY 文件合计约 624 MiB。

页脚：原始幅值对应应变、应变率或仪器输出尚未确认，绝对采集时间也未提供。

### 讲解备注（不上屏）

一对样本包含一个 `x` 和一个 `y`，因此 312 对对应 624 个二维数组，不能把它说成 624 对。正式文件分别为 `train_x/y.npy`、`val_x/y.npy` 和 `test_x/y.npy`。另有 6 组 NPZ 演示样例，不计入正式 312 对的规模；这些演示样例保留未归一化的生成尺度，不应与正式 NPY 直接混用幅值尺度。

每个元素可简单理解为“某个通道在某个时刻的带符号波形幅值”。固定通道读到的是时间波形，固定时间读到的是各通道的瞬时幅值分布。这个阵列描述沿光纤采样位置的波动变化，不能解释为完整的三维地下波场。

包内说明的归一化除数是原始混合输入绝对值的 99.5% 分位数，保存于 `manifest.csv` 的 `normalization` 字段。分位数归一化不限制所有数值落在 `[-1, 1]`。将幅值乘回该除数也只能恢复原数值尺度，不能补出缺失的物理单位。

400 Hz 来自代码及元数据声明。时间范围是样本内部的相对时间，不代表真实地震的绝对发生时间；拼接噪声的窗口也不能当作同一场地同一时段的连续实测记录。

用一张紧凑的维度说明表，标出 `312 对`、`128 通道`、`4096 点`、`400 Hz`、`10.24 s`，并在旁边注明训练 / 验证 / 测试的划分。米制距离保持“待补充”。

## 第 3 页：数据分布、完整性与时空特点

### 上屏内容

**标题：样本覆盖六档信噪比，并保留通道间到时差与后续振动纹理**

| 分析项 | 主要结果 |
|---|---|
| 数据分布 | SNR 为 −3 / 0 / 3 / 6 / 10 / 15 dB，各 52 对。单震相与 P–S 双震相各 156 对 |
| 缺失情况 | 历史全量审计未发现必需数组缺失或 NaN / Inf。单震相样本的 P–S 间隔留空属于不适用 |
| 异常情况 | 历史审计未发现全零、恒定或完全重复样本。幅值可超出 ±1，需区分归一化后的尖峰与数据错误 |
| 空间结构 | 邻近通道具有相关波形，到达时间随通道变化，形成倾斜条带，同时存在局部幅值和纹理差异 |
| 时间变化 | 信号到达后出现主波动及后续尾波。合成中心频率参数约 7–14 Hz，P–S 到时差约 1–4 s |

页脚：各划分的噪声来源切片 ID 两两互斥。质量结论引自 2026-10-25 的全量审计，半合成结果需通过真实事件数据进一步验证。

### 讲解备注（不上屏）

六档 SNR 在训练集各有 40 对，在验证集和测试集各有 6 对。单震相 / P–S 双震相在三个划分中均各占一半。这些分布来自人为设计，不能解释为真实场地中的自然发生比例。SNR 标签采用生成时的信号有效区间口径，不应直接当作全窗口重新计算的 SNR。

缺失要分两类：既有审计记录显示波形数组没有 NaN / Inf，元数据中的 156 个单震相样本没有 P–S 间隔是合理留空；而原始物理单位、通道间距、采集时间和场地信息属于资料缺口，不能说“数据完全没有缺失”。

各划分使用的背景噪声来源切片数为 56 / 12 / 12，共 80 个来源切片，ID 集合互斥，也未使用配置中的 3 个保留切片。已有审计发现的完全重复样本数为 0，但这不证明所有样本都统计独立，原始连续记录的近似重叠情况仍缺少资料确认。

解释图时，先指出中图 `y` 的倾斜条带：它表示同一波形特征到达不同通道的时间不同。随后说明条带后的复杂纹理也包含目标信号，不能一概当作待去除的噪声。左图 `x` 是叠加噪声后的输入，右图 `x-y` 是由现有配对数组计算的噪声残差，受 float16 存储舍入影响。

合成中心频率参数的精确范围为 7.015–13.971 Hz，这不是整段波形的完整频带。P–S 间隔为 1.002115–3.994887 s，仅针对双震相样本。三页汇报中保留近似范围即可。
