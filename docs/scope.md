## 实验目标

当前数据集满足 `x = y + noise`：`x` 是带噪 DAS 波场，`y` 是干净真值。目标是使用 ResShift 学习去噪关系，在推理时仅输入 `x`，恢复得到接近 `y` 的预测 `y_hat`。

## 范围

先在现有半合成 DAS 配对数据上验证去噪效果，暂不扩展为真实 DAS 数据泛化验收。首版网络与备选路线见 [model.md](model.md)。

- 本文仅维护 ResShift 训练适配设计；数据集审计任务、审计脚本、审计回归测试和既有检查报告不纳入本次开发同步范围。
