## 完整验证与推荐频率

训练验证从带噪输入执行完整反向链，不能用训练单步预测替代；全部 val 样本参与，test 只在方案冻结后最终评价。完整链的 15 步定义见 [diffusion.md](diffusion.md)，固定评估随机流见 [randomness.md](randomness.md)。

| 项目 | 推荐，待确认 |
| --- | --- |
| 完整验证 | 第 1 epoch 后一次，之后每 10 epoch 一次，最后一轮确保验证；完整覆盖 val 36 对、每对完整采样 15 步 |

完整验证安排对应 epoch `1,10,20,...,300`，共 31 次；每次 36*15=540 次单样本等价前向，共 16740 次。即使延长验证间隔，也不能减少为只运行部分反向链或只挑一部分验证样本。第 1 轮的验证用于尽早确认完整采样可运行，后续每 10 轮观察效果变化；每轮 last 保存仍独立执行，不与验证间隔绑定，不产生按指标挑选的 best checkpoint。训练前可按既定指标口径计算一次 noisy 输入基线作为参照，test 在方案冻结后进行最终评价。

## DDP 下的验证阶段

双卡验证调度必须显式处理 DDP 同步：若仅 rank 0 执行完整验证，采样传入解包后的 `ddp_model.module`，所有 rank 在一致的验证前后阶段同步；其他 rank 不能一边等待 barrier 或 RNG 收集、一边让 rank 0 独自调用 DDP 包装对象的前向。rank 0 在 eval、无梯度及隔离评估 RNG 的作用域完成验证，结束后恢复训练模式和训练 RNG，再与其他 rank 一起进入保存及下一轮。若改为所有 rank 分担验证，则各 rank 使用解包模型按固定样本 ID 分片采样、汇总指标，确保每个 val 样本只统计一次，并保持共同的阶段同步顺序。单卡调试使用原模型。该约束不决定尚待确认的验证频率，也不表示已复现双卡死锁；目标环境须验收“训练→完整验证→保存→下一轮训练”的连贯运行。参考：[PyTorch DDP 同步说明](https://docs.pytorch.org/docs/2.10/generated/torch.nn.parallel.DistributedDataParallel.html)。

## 指标与计算口径

设单个完整样本真值为 `y`，最终反向采样输出为 `y_hat`，样本元素数为 `M = 128 * 4096`。

| 指标 | 定义与用途 | 已确定或待统一事项 |
| --- | --- | --- |
| RMSE，越低越好 | `sqrt(sum((y_hat - y)^2) / M)`，衡量整体数值误差 | 已确定使用当前数据集归一化尺度，不还原原始幅值 |
| 相对 L2 误差，越低越好 | `norm(y_hat - y, 2) / norm(y, 2)`；二维数组按全部元素的欧氏范数计算，即 Frobenius 范数 | 当前脚本将零能量真值的比值写为 JSON `null`，从逐样本均值排除并记录有效数；不是相对于 noisy 误差的比值 |
| SSIM，越高越好 | 比较二维波场局部均值、方差和协方差 | 当前脚本使用 FP64、11×11 Gaussian、sigma=1.5、总体协方差、反射填充并统计全部像素；不额外 min-max、平移或截断 |

当前脚本同时保存逐样本值和均值；全局 RMSE 先汇总平方误差再开方，全局相对 L2 使用整个测试集的范数，不是逐样本指标均值。SSIM 默认使用 `test_y` 全局 `max-min`，可用 `--ssim-data-range` 显式固定；noisy、预测和不同 checkpoint 的比较须采用同一范围。

按 `manifest.target_snr_db` 六档目标 SNR 分组仍是后续建议，脚本未实现；标签不能称为已独立核实的整段能量 SNR。成功门槛和 best 选模仍未冻结。

第一版不另列 SNR、相关系数、频谱误差等数值评估指标。已有 baseline 的 `error_signal_corr` 实际计算余弦相似度，本次不沿用该名称或将其加入约定指标。

### 2026-10-27 的 SSIM 历史讨论（非当前脚本参数）

以下保留历史讨论。当前回传结果采用上述反射填充及全像素均值，不能与下文裁边有效窗口方案直接混比。

局部 SSIM 公式：

```text
SSIM(p, q) = ((2*mu_p*mu_q + C1) * (2*cov_pq + C2))
             / ((mu_p^2 + mu_q^2 + C1) * (var_p + var_q + C2))

C1 = (K1 * L)^2
C2 = (K2 * L)^2
```

其中 `L` 对应 `data_range`，只是稳定常数的计算参数，不会归一化输入。当前 q99.5 归一化并不保证振幅严格位于 `[-1,1]`，因此尚不能直接固定 `L=2`。推荐事先约定统一的取值规则，不随各模型预测极值改变。

| 参数 | 已讨论的推荐起点 | 状态 |
| --- | --- | --- |
| 计算对象 | 单个完整 `128×4096` 波场，使用局部滑动窗口，不拼接 batch 或跨样本计算 | 推荐，待最终确认 |
| 窗口大小 | `11×11`，即 11 道乘 11 个时间点；400 Hz 下首末时间跨度 25 ms | 推荐，待最终确认 |
| 步长 | 道轴和时间轴均为 1 | 推荐，待最终确认 |
| 窗口权重 | 归一化高斯权重，`sigma=1.5` | 推荐，待最终确认 |
| 边界 | 仅统计完整落入数组的有效窗口，不构造边界外数据 | 推荐，待最终确认 |
| 局部统计 | 使用加权总体方差与协方差；如采用 scikit-image，明确 `use_sample_covariance=False` | 推荐，待最终确认 |
| 稳定常数 | `K1=0.01`、`K2=0.03` | 推荐，待最终确认 |
| 动态范围 | 显式配置统一的 `data_range`；具体数值或规则未定 | 待定 |
| 数组维度解释 | DAS 道轴属于二维波场的一条轴；如采用 scikit-image，单样本使用 `channel_axis=None` | 适配必需 |
| 汇总 | 对有效位置的局部 SSIM 求算术平均，得到单样本得分 | 推荐，待最终确认 |

在上述窗口和边界方案下，局部 SSIM 图为 `118×4086`，共 482148 个窗口位置。边缘数据仍进入相邻有效窗口，但不计算越界窗口。整个波场只用一个全局窗口在数学上也可行，但与上述局部 SSIM 口径不同，尚未被选为本项目方案。

高斯卷积可高效计算局部统计量：`mu_p = G*p`、`var_p = G*(p^2) - mu_p^2`、`cov_pq = G*(p*q) - mu_p*mu_q`。这里的高斯核固定，不参与训练；SSIM 后续还有非线性运算，因此整体不是一次卷积。

SSIM 在此作为二维结构指标，不能单独证明振幅和物理传播关系完全正确，应与 RMSE、相对 L2 误差共同解释。`11×11` 是通用起点，不是当前 DAS 数据上已验证的最优窗口。
